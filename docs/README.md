# DAP core docs

These notes match this tree (core version `0.1.0`, plus inbox follow-ups).

- [Architecture](architecture.md) covers the binary, the window, loopback, tokens, and plugin processes.
- [CLI](cli.md) covers every `da` command.
- [Plugin authoring](plugin-authoring.md) is the guide to write a plugin from, including the schema, the protocol, the tutorial, and how to add a Composio toolkit.
- [Plugins](plugins.md) covers `plugin.yaml` and `dap.plugin.v1`.
- [Runtime](runtime.md) covers the scheduler, inbox, guardrails, ledger, secrets, doctor, files, tests, and limitations.
- [Layout](layout.md) covers card views, density, and the plugin contract.
- [Theme](theme.md) covers System, Light, and Dark.
- [Inbox follow-ups](inbox-followups.md) covers the watcher, Connections, and Gmail and Outlook.
- [Composio](composio.md) is the connectivity layer: the SDK decision, Gmail and Outlook, privacy, and releases.
- [Release](release.md) covers install, Gatekeeper, SmartScreen, and checksums.
